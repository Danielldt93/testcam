Hosting & connection
Serve this file over HTTPS (or localhost for development) and open it directly in Chrome or Edge on Windows with Bluetooth enabled. Click Find & connect scale and select your indicator. Close any scanner app already connected to the scale. Safari and Firefox do not provide standard native Web Bluetooth support.

If the scale is absent, enable Show all BLE devices and retry. An unnamed device can still be the scale; connecting checks for service FFB0. If none appears, confirm the scale's BLE module is installed and advertising. Device discovery requires a button click and your permission.

The print button prints this page's displayed reading using the browser; it does not command a physical scale printer. All readings stay in this browser; this page sends no data to a server.
