    Help
    
  Open this page over HTTPS (or localhost) in Chrome or Edge with Bluetooth on. CONNECT SCALES only lists devices that advertise the IND 180SS service FFB0. Close any other app that is already connected to the scale.
    
  Browsers do not reveal a Bluetooth device's MAC address, so the label shows the device name and a browser-assigned ID instead of an address like 74:48:93:…
    
  SAVE stores the current reading in this browser only; RECALL lists saved readings. PRINT sends the indicator's PRINT key and, if a Bluetooth thermal (ESC/POS) printer is connected, prints a weight ticket on it.
    
  Add ?demo to the address to try the interface without a scale.
